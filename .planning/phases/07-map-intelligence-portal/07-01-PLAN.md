# Plan 07-01: Map Intelligence Portal Integration

## Objective

Port a simplified and refactored version of the legacy map intelligence dashboard into this repository, compile it under the `/intelligence` route using a Vite multi-page configuration, modularize the code into ES6 files, style with forest green + warm cream design tokens, and integrate static property match filtering from the Excel inventory.

## must_haves

### truths
- D-01: Serve `/intelligence` as a native separate page using a Vite multi-page configuration (creating `/intelligence/index.html`)
- D-03: Break down monolithic script into `map.js`, `sidebar.js`, `filters.js`, `ui.js`, `data.js`
- D-04: Remove GSAP camera looping tour and auto-cycling stats cards
- D-05: Style overlays in forest green (`#004337`), warm cream (`#FAFAF5`), and white (`#FFFFFF`)
- D-06: Simplify map styles to hide dense POIs, highway shields, and landmark clutter
- D-07: Query matches locally against property database imported from `Inventory for app (1).xlsx`

### behaviors
- Clicking country (India/UAE) zoom transition moves to city polygons
- Clicking Pune/Mumbai/Dubai zoom transitions focus on trade area markers
- Selecting filter parameters (Category, Size, Budget) queries matching trade areas and highlights them on the map
- Minimized sidebar renders Available Properties list cards and core stats (Daily footfall, Rent, Avg spend)
- Contact CTA triggers lead capture form submission to remote API
